# Candidate validation

See `validation/RESULTS.json` for actual replay results and the package `VALIDATION_REPORT.md` for interpretation. Run `python3 governance/validation/replay_checks.py` from any working directory. All acceptance and channel fixtures are synthetic and create no real authority.

The suite preserves upstream positive/negative cases and adds coverage for operational timing, existing mission IDs, traversal refusal and proposed-discretion refusal. Historical identifiers require either retention or an explicit retirement disposition; no permanent all-identifiers-must-remain rule is imposed. No clause is actually retired in this candidate.

No independent review, live reviewer availability, agent compliance, project runtime behavior or productivity improvement is proven by these structural checks.
