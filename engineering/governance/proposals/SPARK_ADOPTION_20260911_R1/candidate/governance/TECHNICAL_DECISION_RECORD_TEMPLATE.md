# Technical Decision Record Template

Governed by [Project Agent Instructions](AGENT_RULES.md) I10.2.

**T.1** The decision owner records each decision that I10.2 requires using the fields below.

**T.3** Each record identifies an observable revisit condition or a governing assumption whose change invalidates the decision.

**T.4** The decision owner stores each TDR at the A2 location and cites related mission, review and source records rather than duplicating their evidence.
