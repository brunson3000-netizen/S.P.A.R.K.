## Windows agent workflow (kit 1.2.0)

Operational convention for agent sessions on Windows. It grants no authority of its own and changes no rule of this project; this project's own instructions govern wherever they differ.

- On Windows, read `docs/agent_workflow/WINDOWS_EXECUTION_PROFILE.md` before running commands. It records the Python interpreter, the `claude.cmd` and `codex.cmd` entry points, the shell, the line-ending rules, the durable D: repository rule and the Operator's standing Desktop Commander and read/fetch grants with their sources.
- Before cooperative builder and reviewer work, read `docs/agent_workflow/SHARED_AGENT_INSTRUCTIONS.md` and your role sheet in the same folder. Architects launch from `docs/agent_workflow/WINDOWS_LAUNCH_BRIEFS.md`.
- For integration, troubleshooting and advice, follow `docs/agent_workflow/DOCUMENTATION_FIRST_POLICY.md`, including its engineering-partnership section.
- Record the SHA-256 of each instruction file you actually read. `docs/agent_workflow/WINDOWS_AGENT_KIT.sha256` identifies the kit files; `docs/agent_workflow/KIT_SOURCE.md` gives the source and the update path.
